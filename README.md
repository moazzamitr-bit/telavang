# تلاونگ AI OS

**Telavang Intelligent Operations Platform**

پروتوتایپ سطح سازمانی برای سیستم عامل هوشمند عملیات تلاونگ — پلتفرم Agentic AI برای مدیریت یکپارچه زنجیره تولید تخم‌مرغ و محصولات پروتئینی.

## اجرا

```bash
npm install
npm run dev
```

سپس به آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173`) بروید.

## قابلیت‌های کلیدی

- **فرمانده عملیات تلاونگ** — رابط AI سازمانی با ۴ سناریوی تعاملی
- **نمای کلی عملیات** — داشبورد اجرایی KPI
- **مزارع، خوراک، تولید، کیفیت، موجودی، فروش، مالی**
- **نیروی کار ۸ ایجنت هوشمند**
- رابط کامل **فارسی / RTL** با فونت Vazirmatn
